TFT 参数分析系统 v0.4.0

运行方式
双击“TFT参数分析系统_v0.4.0.exe”即可打开程序，无需安装 Python 或运行安装依赖脚本。
适用于 Windows 10/11 64 位系统。单文件程序启动时会临时解包运行环境，可能需要等待数秒。

基本操作
1. 从顶部列表选择 n 型或 p 型公开示例，点击“加载示例”；也可以打开自己的 TXT、CSV、TSV 或 XLSX 文件。
2. 确认器件类型、拟合方法和电压区间，点击“计算并更新结果”。
3. 将鼠标移到曲线上，可查看附近的数据点或模型预测。
4. 点击“导出分析结果”，选择保存位置；“保存截图”可以单独保存当前界面。

程序内置六个公开实测示例，复制 EXE 到其他文件夹后仍可使用。
压缩包中的 data 文件夹另行保留示例数据和来源记录，便于查看原始材料。
“开灯”和“关灯”指测量时的照明状态。完整数据来源与使用条件见 docs 文件夹。

p 型数据请保留电压、电流的测量符号；仪器只输出正电流幅值时，可以勾选“反转电流符号”。
迁移率需要 W、L、Ci、Vds 等条件，并应确认所选工作区。示例中的 Ci 默认留空。

文件保存
打开和保存对话框默认进入用户的“文档”文件夹，可以自行选择其他位置。
原始数据不会被修改，软件退出后也不会删除已经导出的分析结果。
