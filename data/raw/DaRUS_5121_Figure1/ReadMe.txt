This data repository includes:

- Raw data (.csv, .xlxs)
- Evaluation scripts (.py) 
- Plotted (in some cases processed) data (.npy)
- Evaluation/plotting scripts (.py) 
- Documentation files (.txt)
- Paper figures (.png)
- Paper (.pdf) 

The data is structured in folders of the paper figures

Each folder consists of: 

- Paper figure
- Raw data and evalution script folder
  - Raw data
  - Evalution/plotting script
  - Documentation file
